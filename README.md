# 4B5B-NRZI Transceiver Simulation using eSim

This repository contains the design and simulation files for a 4B5B-NRZI transceiver implemented using eSim.

## 📂 Repository Contents

### 🔧 Schematic Files
Contains the individual eSim schematic files used to build the different parts of the project.

### 📊 Simulation Results
Contains the simulation graphs and waveforms obtained from the project.

### 📄 Project Abstract
Contains the abstract and detailed explanation of the project, including the system design, methodology, and results.

## ▶️ How to Open the Project

1. Install and open **eSim**.
2. Download or clone this repository.
3. Open the required schematic file using eSim.
4. Run the simulation to observe the corresponding output.
5. Refer to the simulation graphs and project abstract for the results and project details.

## 🛠️ Tools Used

- eSim
- KiCad
- NgSpice
